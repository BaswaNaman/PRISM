Multi-Source Ingestion & Validation Specs

How PRISM ingests Web, PDF, and Text sources while retaining field-level provenance, verbatim evidence, validation status, and review routing.

1. Secure Web Ingestion

Retrieves permitted product pages through SSRF-safe httpx requests and parses them with BeautifulSoup:

  • Uses browser-compatible request headers with bounded response handling
  • Strips navigation, footers, ad blocks, and boilerplate scripts
  • Exposes HTTP status codes and raw text length preview in UI
2. Overconfidence Guardrails

Prevents AI overconfidence on sparse or failed fetches:

  • Content < 200 chars triggers automated warning flag
  • HTTP errors (403, 404, 500) force zero confidence across fields
  • Automatically routes unverified products to Review Queue
3. Deterministic Validation Engine
  • Voltage Bounds: 0V to 1000V DC/AC
  • Current Bounds: 0A to 200A capacity
  • IP Code Regex: Validates against standard codes (IP20-IP69K)
  • Contradictions: Flags submersible items tagged with indoor-only IP20 rating
4. Multi-Source Traceability
  • Origin Tagging: Explicitly marks the domain supporting each extracted field
  • Verbatim Quotes: Displays exact source snippet evidence in quote inspector
  • Raw Text Preview: One-click inspector showing raw scraped content
5. Source Policy & Identity Verification

The active source policy is evaluated before retrieval, and product identity is checked before evidence is accepted:

  • Preferred: manufacturer sources with exact MPN and brand/manufacturer corroboration
  • Policy-dependent: verified distributor sources may be accepted and flagged under allow_distributors
  • Rejected as trusted evidence: marketplaces, encyclopedias, forums, and community-authored sources
  • Strict mode: a data/approved_domains.txt allow-list overrides the category rules entirely
6. Commerce Output Readiness

Five description formats are built from trust-gated values and mapped into the delivery schema:

  • Invoice: ≤40 chars, ALL CAPS, approved abbreviations
  • Mobile: 60–80 chars · Title: ≤200 · Long: ≤1000 · Web: prose
  • Units: approved abbreviation with a mandatory space; decimal inches rendered as trade fractions (0.375 → 3/8 in)
  • LOV: validation runs when an approved vocabulary is loaded; otherwise conformance is reported as unavailable rather than assumed
